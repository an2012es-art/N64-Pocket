# N64 Pocket — واجهة تجريبية ثلاثية الأبعاد لـ Nintendo DSi

## ما الذي يفعله هذا المشروع؟
- يعرض مكعبًا ثلاثي الأبعاد دوّارًا باستخدام عتاد 3D في Nintendo DS/DSi.
- يعرض قائمة خانات تجريبية على الشاشة السفلى.
- يدعم UP/DOWN للتنقل، A للتفاصيل، B للعودة، وSTART لإظهار/إخفاء المعلومات.
- ألوان بنفسجية وسوداء مع لمسات وردية.

## ما الذي لا يفعله؟
هذه **ليست محاكاة Nintendo 64** حتى الآن. لا يوجد CPU خاص بـ N64، أو محاكاة RSP/RDP، أو صوت، أو تحميل ROM. العناصر في القائمة خانات توضيحية فقط. صنع محاكي N64 كامل على DSi مهمة صعبة جدًا، ولا يمكن ضمان تشغيل الألعاب.

## المتطلبات
1. كمبيوتر يعمل بنظام Windows أو Linux.
2. تثبيت devkitPro من: https://devkitpro.org/
3. تثبيت أدوات Nintendo DS development، بما فيها `devkitARM` و`libnds` عبر devkitPro pacman.
4. تشغيل الطرفية التي يوفرها devkitPro (MSYS2/MinGW64 أو الطرفية الموصى بها في دليل تثبيتك).

## البناء على Windows
1. فك ضغط `N64_Pocket_project.zip` في مجلد، مثل `C:\N64_Pocket`.
2. افتح طرفية devkitPro وانتقل إلى المجلد:
   ```sh
   cd /c/N64_Pocket
   ```
3. شغّل:
   ```sh
   make
   ```
4. عند نجاح البناء، سيكون الملف الناتج `N64_Pocket.nds` في مجلد المشروع.
5. انسخه إلى بطاقة SD، ثم شغّله من TWiLight Menu++ على جهاز DSi مجهّز لتشغيل homebrew.

## التحكم
- السهم الأعلى / الأسفل: اختيار خانة.
- A: عرض تفاصيل الخانة.
- B: إغلاق التفاصيل.
- START: تبديل شاشة المعلومات.

## استكشاف الأخطاء
- إذا ظهر `DEVKITARM is not set`: افتح طرفية devkitPro الصحيحة بدل CMD العادي.
- إذا ظهر خطأ من `make`، احفظ سجل الخطأ كاملًا وأرسله للمساعدة في إصلاحه.
- لا تضع ملفات ألعاب تجارية ضمن المشروع، ولا تحتاج إلى ROM لاختبار الواجهة.

## الحالة الحالية
- ملفات المصدر وMakefile موجودة.
- لم يتم بناء ملف NDS أو اختباره على جهاز فعلي في هذه البيئة.
- الكود يهدف إلى واجهة تجريبية؛ قد يحتاج إلى تعديلات توافقية حسب إصدار devkitPro/libnds.


## البناء عبر GitHub Actions (دون تثبيت devkitPro على Windows 7)
1. أنشئ حسابًا في GitHub من المتصفح، ثم أنشئ مستودعًا جديدًا باسم `N64-Pocket` واجعله Private إن كنت تفضّل الخصوصية.
2. ارفع جميع ملفات المشروع والمجلدات كما هي، مع التأكد من رفع المجلد `.github/workflows` والملف `build.yml`. عند الرفع عبر المتصفح قد تحتاج إلى إنشاء الملفات/المجلدات من خيار **Add file → Create new file** أو استخدام رفع الملفات مع الحفاظ على البنية.
3. بعد رفع الملفات، افتح تبويب **Actions** في المستودع.
4. اختر سير العمل **Build N64 Pocket NDS** ثم اضغط **Run workflow**. يمكن أيضًا أن يبدأ تلقائيًا بعد دفع تغييرات إلى فرع `main` أو `master`.
5. انتظر انتهاء المهمة. إذا فشلت، افتح المهمة واقرأ سجل **Build Nintendo DS application**.
6. إذا نجحت، افتح صفحة تشغيل الـ workflow وابحث عن قسم **Artifacts** في أسفل النتائج، ثم نزّل `N64-Pocket-NDS`. سيكون داخله `N64_Pocket.nds`.
